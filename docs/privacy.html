Privacy Policy

Last updated: 2026-08-28

DefaultSorter for Amazon is a browser extension (Firefox & Chrome) that lets you choose a default sort order (e.g. Best Sellers) for Amazon search results, instead of Amazon's own "Featured" default. This policy explains what the extension accesses and why.

Summary

  • The extension does not operate its own server, does not use analytics, and does not transmit any of your data anywhere.
  • It makes no network requests of its own. It only rewrites the destination of navigations you already make to Amazon search pages, adding a sort-order query parameter before the page loads.
  • Your chosen sort order and language preference are stored only in your browser's local extension storage (browser.storage.local), via the standard storage permission. None of this leaves your device.
  • The extension only acts on Amazon search-result pages (amazon.<tld>/s?...) on the supported Amazon domains listed in manifest.json. It does not run on, read, or access any other website.
  • No account, sign-in, or personal information is required or collected.

Permissions

PermissionWhy it's needed
storage Saves your chosen default sort order and language preference locally so they persist between browser sessions.
declarativeNetRequest Rewrites the URL of an Amazon search-result navigation to include your chosen sort parameter, before the page loads — this is what avoids a visible reload/flicker on the normal (non-JavaScript-driven) search path.
webNavigation Detects the rare case where Amazon renders a search result via client-side JavaScript navigation (e.g. clicking a search-suggestion) rather than a full page load, so declarativeNetRequest never sees a request to rewrite. Used only to notice this happened, not to read browsing history.
tabs Used together with webNavigation above: forces a real reload with the sort parameter applied for the client-side-navigation case described above.
Host access to the supported Amazon domains (see manifest.json) Required for the two permissions above to apply — the extension only acts on Amazon search-result pages on these domains, and does not run on any other site.

Third parties

DefaultSorter for Amazon is an independent, unofficial project and is not affiliated with or endorsed by Amazon. It does not share your data with Amazon, advertisers, or any other third party — it has no mechanism to do so.

Changes to this policy

If this policy changes, the "Last updated" date above will be revised and the change will be reflected in the extension's GitHub repository.
