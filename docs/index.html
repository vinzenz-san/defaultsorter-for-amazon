DefaultSorter for Amazon

A free browser extension for Firefox and Chrome that lets you pick a default sort order — Best Sellers, Price, Rating, or Newest — for Amazon search results instead of "Featured", applied automatically across every Amazon domain.

Not yet on the storesGet it on GitHub

What it does

Amazon's search results default to "Featured" sorting. DefaultSorter for Amazon rewrites the search URL to your chosen sort order before the results page loads, so you see what you actually want, every time.

Six sort orders to choose from

Featured (Amazon's default, i.e. off), Best Sellers, Price low-to-high, Price high-to-low, Avg. Customer Review, or Newest Arrivals — picked once in the toolbar popup, applied to every search.

Works on every Amazon domain

amazon.de, .com, .co.uk, .fr, and 19 more — the sort keys are the same internal values across domains, verified live rather than assumed.

No visible reload, in the normal case

The sort parameter is added to the URL before the results page loads, not after. A fallback only kicks in for the rare client-side-rendered search (e.g. clicking a suggestion), which Amazon itself can't avoid reloading.

Private, open source

No account, no analytics, no data sent about you or your searches. Your preference is stored locally in your browser. Free and open source under the MIT license.
